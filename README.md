# Ľahká Stepper stránka

Samostatný React/Vite projekt s použitým `Stepper` komponentom.

## Spustenie

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Výstup bude v priečinku `dist`.

## Súbory

- `src/Stepper.jsx` – komponent Stepper
- `src/Stepper.css` – štýly stepperu
- `src/App.jsx` – ukážková stránka
- `src/index.css` – globálny dizajn stránky
